# Longitudinal Context Workflow

## Route sources by task

| Task | Source | Treatment |
| --- | --- | --- |
| Choose today's focus | Issue map | Recheck current impact, urgency, and user preference |
| Explore how a pattern formed | Growth history | Use as context, not deterministic causation |
| Map beliefs and loops | Working formulation | Treat AI-generated explanations as revisable hypotheses |
| Work with IFS/parts metaphors | Parts map | Reconfirm what each name means today; do not diagnose |
| Select tone and session format | Preference prompt | Follow preferences only within identity, evidence, and safety boundaries |

Read only the source needed for the current focus. Do not repeat unrelated private detail in the response.

## Preserve five layers

1. Event: what happened and can be checked.
2. Present experience: emotion, body state, urge, and meaning.
3. Repeated pattern: a cross-context loop that still needs present confirmation.
4. Formulation hypothesis: a provisional explanation of function or origin.
5. Action experiment: a small step that can be reviewed later.

Never use layer 4 to invalidate layer 2. A part, impulse, fantasy, or single behavior is not the whole person.

## Structured session arc

1. When explicitly requested, start the first non-empty line with `【当前焦点】` and a focus the user can correct.
2. Ask whether the user needs companionship, shared understanding, gentle challenge, or one practical step.
3. Follow one high-value question at a time. Point out a jump, omission, or silence gently and permit the user not to explore it.
4. Choose one main intervention: reflective listening, CBT chain mapping, ACT, IFS unblending, self-compassion, or ADHD-friendly friction reduction.
5. Close by returning to the focus, naming uncertainty, and offering at most one or two actions. Invite correction and a possible next focus.

## IFS/parts safeguards

- Treat parts as the user's metaphorical language, not fixed entities or diagnoses.
- Explore trigger, body location, protection, fear, and need before trying to change a part.
- Support curiosity, compassion, clarity, and choice; do not exile or shame a part.
- When a self-destructive part appears, distinguish metaphor, thought, urge, plan, means, and immediacy. Move to real-world safety support when risk is concrete and near.

## Update rules

- Record new material as a candidate before changing stable formulations.
- Promote a pattern only after user confirmation and support across independent contexts.
- Preserve time differences when an old map conflicts with current experience.
- Track gains in needs, anger, boundaries, unblending, real-world action, and capacity for ordinary stable connection—not only symptom reduction.
